# Rere Documentation

Rere is an executor-compatible Roblox UI library. It bundles Iris into one loadable Luau file, so you do not need Roblox Studio ModuleScripts or `require` paths.

{% hint style="info" %}
The current pinned release is **v0.1.25**. Use an immutable tag in executor scripts.
{% endhint %}

## What you can build

Windows, menus, tabs, collapsing sections, dropdowns, inputs, sliders, tables, plots, configuration panels, runtime tools, and complete debug dashboards.

## Start here

1. Follow [Executor setup](getting-started.md).
2. Copy the [Quickstart](quickstart.md).
3. Browse [Elements overview](elements.md).
4. Run the [full element example](examples.md).

The source repository is [github.com/x8lua/Rere](https://github.com/x8lua/Rere).
